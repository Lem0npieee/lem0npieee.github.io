#### [11. 盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)
本题用两个for[[暴力枚举]]超时了。题解提供了[[双指针]]的方法。
![[Pasted image 20240123174937.png|500]]
只要每次移动短板，就能保证一定会遍历到最大值。
若向内 移动短板 ，水槽的短板 min(h[ i ],h[ j ])可能变大，因此下个水槽的面积 **可能增大** 。
若向内 移动长板 ，水槽的短板 min(h[ i ],h[ j ])不变或变小，因此下个水槽的面积 **一定变小** 。
因此，每轮向内移动短板，所有消去的状态都 **不会导致面积最大值丢失** 。（天才）
所以最后代码如下：
```
int min(int a,int b){
    return a<b?a:b;
}
int maxArea(int* height, int heightSize) {
    int temp=0,ans=0;
    int *l=height,*r=height;
    r+=heightSize-1;
    ans=min(*l,*r)*(r-l);
    while(l!=r){
        if(*l<*r) l++;
        else r--;
        temp=min(*l,*r)*(r-l);
        if(temp>ans)ans=temp;
    }
    return ans;
}
```

```
   public int trap6(int[] height) {
    int sum = 0;
    Stack<Integer> stack = new Stack<>();
    int current = 0;
    while (current < height.length) {
        //如果栈不空并且当前指向的高度大于栈顶高度就一直循环
        while (!stack.empty() && height[current] > height[stack.peek()]) {

        current++; //指针后移
    }
```

#### [53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)
好久前落下超时的题目，用[[动态规划]]试着解决。
如果编号为 i 的子问题的结果是负数或者 0，那么编号为 i + 1 的子问题就可以把编号为 i 的子问题的结果舍弃掉（这里 i 为整数，最小值为 1 ，最大值为 8），这是因为：
* 一个数 a 加上负数的结果比 a 更小；
* 一个数 a 加上 000 的结果不会比 a 更大；
而子问题的定义必须以一个数结尾，因此如果子问题 i 的结果是负数或者 0，那么子问题 i + 1 的答案就是以 nums[i] 结尾的那个数。即：
![[Pasted image 20240129215605.png]]
最后是要返回**最大值**。
代码如下：
```
#本代码用python编写
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        size = len(nums)
        if size == 0:
            return 0
        dp = [0 for _ in range(size)]
        dp[0] = nums[0]
        for i in range(1, size):
            if dp[i - 1] >= 0:
                dp[i] = dp[i - 1] + nums[i]
            else:
                dp[i] = nums[i]
        return max(dp)
```

⭐[[动态规划]]思路：
* 1. 分割成子问题（**状态定义**）
* 2. 找子问题之间的联系（**状态转移方程**）
* 3. 定义dp并初始化
* 4. 写递推并输出

```
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int k = 0;
        for (int i = 0; i < nums.size(); i++) {
            if (i > k) return false;
            k = max(k, i + nums[i]);
        }

```

```
    void reverse(vector<int>& nums, int start, int end) {
        while (start < end) {
            swap(nums[start], nums[end]);
            start += 1;
            end -= 1;
        }

        reverse(nums, k, nums.size() - 1);
```

如何求二叉树的深度？这种题会用到搜索算法。搜索算法分广度搜索和深度搜索。由于这里是想求深度，那自然是深度搜索比较好。
这里还用到了[[递归]]的想法。如果我们知道了左子树和右子树的最大深度 lll 和 rrr，那么该二叉树的最大深度即为 **max( l , r ) + 1**
而左子树和右子树的最大深度又可以以同样的方式进行计算。因此我们可以用「[[深度优先搜索]]」的方法来计算二叉树的最大深度。具体而言，在计算当前二叉树的最大深度时，可以先[[递归]]计算出其左子树和右子树的最大深度，[[递归]]在访问到空节点时退出。
```
int maxDepth(struct TreeNode* root) {
  if(root==NULL)return 0;
  else {
  return 1+fmax(maxDepth(root->left),maxDepth(root->right));
    }
}
```

#### [1702. 修改后的最大二进制字符串](https://leetcode.cn/problems/maximum-binary-string-after-change/)
这道题有点考数学了。

- 操作 1 ：如果二进制串包含子字符串 `"00"` ，你可以用 `"10"` 将其替换。
    `"**00**010" -> "**10**010"`
- 操作 2 ：如果二进制串包含子字符串 `"10"` ，你可以用 `"01"` 将其替换。
    `"000**10**" -> "000**01**"`

其实稍微想一会会发现：
- 用操作二，将**非前缀**的1推到**末尾**。  
	`11110∗∗∗∗∗∗ -> 111100…011111`
- 用操作一，把中间**连续**的0替换为1，末尾留个0  
	`000…0 -> 111…10`
然后你可以发现，无论一开始有多少个0，最后都会只化为一个0（除非全是1）。所以我们可以依照这个规律构造新的字符串
```c++
class Solution {    //看不懂思路也没事，好歹学一下c++代码
public:
    string maximumBinaryString(string binary) {
        int n = binary.size(); //.size():字符串长度
        int i = binary.find('0'); 
        //.find():寻找字符串中的0，如果有返回位置，没有返回npos
```

#### [198. 打家劫舍](https://leetcode.cn/problems/house-robber/)
又来练习动态规划啦！
首先，一间房子有“偷”和“不偷”两种情况。①如果第i间房子偷，那么第(i-1)间房子按照规则就不能偷了。所以偷到的钱数是**dp\[i]=dp\[i-2]+nums\[i]**。
*dp\[i-2]是前(i-2)间房子所能偷到的最大的钱数，nums\[i]是第i间房子的钱数。* ②如果第i间房子不偷，那么前i间房子所能偷到的最大的钱数就是前(i-1)间房子所能偷到的最大的钱数，即**dp\[i]=dp\[i-1]**。
综上，前i间房子所能偷到的最大的钱数是上面两种情况的最大值，
即**dp\[i]=max(dp\[i-2]+nums\[i]，dp\[i-1])** 。
当然，头几间房子得单独拿出来定义。
没有房子 return 0；
只有一间房子 return nums\[0];
有两间房子 return fmax(nums\[0],nums\[1]);
```
class Solution {
public:
    int rob(vector<int>& nums) {
        int size=nums.size();
        if(size==0)return 0;
        if(size==1)return nums[0];
        vector<int> dp=vector<int>(size,0);
        dp[0]=nums[0];
        dp[1]=fmax(nums[0],nums[1]);
        for(int i=2;i<size;i++){
            dp[i]=fmax(dp[i-2]+nums[i],dp[i-1]);
        }
        return dp[size-1];
    }
};
```

#### [41. 缺失的第一个正数](https://leetcode.cn/problems/first-missing-positive/)
一道挺重要的题。
一开始做直接暴力做法（其实感觉也不是很暴力）。先删掉非正数，再升序排序。如果第一位不是1，直接返回1；else遍历判断中间是否空缺，有就返回nums\[i]+1。这里特别注意相邻两数相等的情况（于是判断语句加了个条件）
```C++
class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        if(nums.size()==1){
            if(nums[0]==1)return 2;
            else return 1;
        }
        for(int i=0;i<nums.size();i++){
            if(nums[i]<=0){
                nums.erase(nums.begin()+i);
                i--;
            }
        }
        sort(nums.begin(),nums.end());
        for(auto it:nums)cout<<it<<' ';
        if(nums.front()!=1)return 1;
        else{
            for(int i=0;i<nums.size()-1;i++){
                if(nums[i]+1!=nums[i+1]&&nums[i+1]-nums[i]!=0)return nums[i]+1;
            }
        }
        return nums[nums.size()-1]+1;
    }
};
```
时间复杂度：O(NlogN)
接下来是新方法：[[原地哈希]]。简单说就是把数组本身当成是哈希表。采取的规则是：**数字i的下标是i-1**，即1的下标是0，2的下标是1, ......
![[Pasted image 20240713205718.png]]
黄色箭头表示从左往右遍历，不符合规则的就和那个那个`数字对应的下标` 上的数字交换位置，**直到换到对的为止** 。然后在从左往右遍历一遍，找出那个不符的位置，输出结果。没找到就输出最大的数字+1。
```C++
class Solution {
public:
    void swap(vector<int>& nums,int i,int j){
        int temp=nums[i];
        nums[i]=nums[j];
        nums[j]=temp;
    }
    int firstMissingPositive(vector<int>& nums) {
        int len=nums.size();
        for(int i=0;i<len;i++){
	        while(nums[i]>0 && nums[i]<=len && nums[nums[i]-1]!=nums[i]){  //最后一个条件意思是两个数字一样就不换
                swap(nums,nums[i]-1,i);
            }
        }
        for(int i=0;i<len;i++){
            if(nums[i]!=i+1)return i+1;
        }
        return len+1;
    }
};
```
时间复杂度：O(N)

### 岛屿问题
`是一个图的问题, 本质是dfs, 而dfs本质是回溯` 
**岛屿问题模板**(Java)
```java
// 递归：「当前节点」「该做什么」「什么时候做」
// FloodFill：如果当前位置是岛屿，则填充为海水
//   - 充当了 visited[] 的作用
private void dfs(int[][] grid, int i, int j) {
    int m = grid.length;
    int n = grid[0].length;
    // 越界检查
    if (i < 0 || i >= m || j < 0 || j >= n) return;
    // 如果是海水
    if (grid[i][j] == 0) return ;
    // 否则：1 -> 0
    grid[i][j] = 0;
    // 递归处理上下左右
    dfs(grid, i - 1, j); // 上
    dfs(grid, i + 1, j); // 下
    dfs(grid, i, j - 1); // 左
    dfs(grid, i, j + 1); // 右
}
```

```c++
class Solution {
public:
    vector<vector<int>> pacificAtlantic(vector<vector<int>>& heights) {
        int m = heights.size();
        int n = heights[0].size();
        // 记录可以流入 Pacific Ocean 的格子
        vector<vector<bool>> po(m, vector<bool>(n, false));

        // 处理第 1 行和最后 1 行

            dfs(heights, 0, i, po, heights[0][i]);

            dfs(heights, j, 0, po, heights[j][0]);

        }

            for (int j = 0; j < n; j++) {

                    res.push_back({i, j});
                }
            }
        }
        return res;
    }
```

### BFS算法框架

前文介绍了DFS，也就是回溯算法/深搜，接下来把BFS广搜给补一下。
如果说 DFS 是树的**递归遍历**，那么 BFS 对应的就是树的**层序遍历**，即一层一层的往下遍历。
![[2020401650284440NwZ7OM4.svg|650]]
精髓代码如下：
```c++
vector<std::vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> res;  //储存每一层的节点值
    if (root == nullptr) return res;
    queue<TreeNode*> q;  //用于存储树的节点指针
    q.push(root);
    while (!q.empty()) {
        int size = q.size();
        vector<int> vec;  //存储当前层的节点值
        for (int i = 0; i < size; i++) {
            TreeNode* cur = q.front();
            q.pop();
            vec.push_back(cur->val);
            if (cur->left != nullptr) q.push(cur->left);
            if (cur->right != nullptr) q.push(cur->right);
        }
        res.push_back(vec);
    }
    return res;
}
```
`注：层次遍历是可以携带层级数据，即可以知道每次处理的是第几层`

```c++
                }
```

## [138. 随机链表的复制](https://leetcode.cn/problems/copy-list-with-random-pointer/)

学思路：使用哈希表 (unordered_map) 
- **创建新节点，但保持指针结构不变**：在第一次遍历链表时，我们仅仅需要为每个原始节点创建一个对应的新节点（即复制节点），但不连接它们。为了保留旧节点和新节点的映射关系，我们可以使用哈希表来存储这一映射。键是旧节点，值是新节点。
    
- **构建 `next` 和 `random` 指针**：在第二次遍历时，我们就可以利用哈希表快速找到旧链表节点对应的新链表节点，并把 `next` 和 `random` 指针都正确地连接起来。由于我们在哈希表中存储了每个旧节点到新节点的映射关系，直接查找对应的节点并赋值 `next` 和 `random` 就可以了。

```  c++
class Solution {
public:
    Node* copyRandomList(Node* head) {
        if(head==nullptr)return nullptr;
        Node* cur=head;
        unordered_map<Node*,Node*> map;
        //创建旧、新节点的映射
        while(cur!=nullptr){
            map[cur]=new Node(cur->val);
            //把旧节点cur作为键，把新创建的节点作为值，存入哈希表中
            cur=cur->next;
        }
        //构建next和random指针
        cur=head;
        while(cur!=nullptr){
            map[cur]->next=map[cur->next];  //神操
            map[cur]->random=map[cur->random];  //神操
            cur=cur->next;
        }
        return map[head];
    }
};
```

### 详解归并排序/分治法

#### 算法思想

「归并排序」其实是一种分而治之的思想。需要把 10 个数字排好序，先分一半，各自排好后，然后合并。
  **简而言之：先分后治
  
  ![[1526101657783570EmOMLr5.svg]]**
  
现在来分析一下「归并排序」的时间复杂度
对于长度为`n`的数组来说，在「分」的过程中，会构建出如上图所示的一棵树，其高度为`logN`，每一层均有`n`个节点；在「治」的过程中，每一层就是合并两个有序数组，其时间复杂度为`o(N)`；所以最终时间复杂度为`o(nlogn)`

#### 算法框架
```
class MergeSort {
private:
    std::vector<int> temp;  //一个全局都要用到的辅助小数组

//分
    void sort(std::vector<int>& nums, int low, int high) {
        if (low == high) return;
        int mid = low + (high - low) / 2;
        sort(nums, low, mid);  //左半排
        sort(nums, mid + 1, high);  //右半排
        merge(nums, low, mid, high);  //合排
    }

//治
    void merge(std::vector<int>& nums, int low, int mid, int high) {
        for (int i = low; i <= high; ++i) temp[i] = nums[i];
        int cnt = low;
        int i = low, j = mid + 1;
        while (i <= mid || j <= high) {
            if (i > mid) nums[cnt++] = temp[j++];  //如果i先到头了，把j剩下的插上（注意这个要写在前面防止出错）
            else if (j > high) nums[cnt++] = temp[i++];  //如果j先到头了，把i剩下的插上（注意这个要写在前面防止出错）
            else if (temp[i] <= temp[j]) nums[cnt++] = temp[i++];  //哪个小哪个先往里面插
            else if (temp[i] > temp[j])nums[cnt++] = temp[j++];  //哪个小哪个先往里面插
        }
    }

//主函数
public:
    void sort(std::vector<int>& nums) {
        temp.resize(nums.size());  //重新给辅助小数组分配空间,切记!!
        sort(nums, 0, nums.size() - 1);
    }
};
```

```
    int ans=0;

    void sort(std::vector<int>& nums, int low, int high) {

        sort(nums, low, mid);
        sort(nums, mid + 1, high);

        //最关键的部分 ↓
        int end=mid+1;

            while(end<=high && (long)nums[i]>(long)2*nums[end])end++;

        }
```

#### [23. 合并 K 个升序链表](https://leetcode.cn/problems/merge-k-sorted-lists/)

两种方法：优先队列、分治法

##### 法一：优先队列
优先队列能自己将里面的元素按一定顺序排列，然后我们每次只需拿top()的元素出来排就行。但是这里是拿好几个链表存的，最多只能比较第一位，怎么办？

当我们把其中一个链表的首个元素加进newHead排序时，我们可以**把该元素后续的那串子链表重新塞回优先队列里**，然后优先队列又会重新排序，以此类推。

![[Pasted image 20241028211151.png]]
步骤：
- 初始队列中加入`k`个链表的头节点。
- 每次弹出当前值最小的节点；
- 将节点的下一个非空节点加入队列；
- 直到队列没有节点合并结束。
```c++
struct minCompare {    //minCompare通过重载operator()来实现较小的值优先被弹出,学会！学会！学会！
    bool operator()(ListNode* a, ListNode* b) {
        return a->val > b->val;
    }
};

    ListNode* mergeKLists(vector<ListNode*>& lists) {
        if(lists.empty())return nullptr;
        priority_queue<ListNode*, vector<ListNode*>,minCompare> p; 
        //<元素类型，底层容器类型(使用其增删改查函数)，比较规则>
        for(auto list:lists){
            if(list)p.push(list);
        }
        ListNode* newHead=new ListNode;
        ListNode* temp=newHead;
        while(!p.empty()){
        ListNode* newNode=p.top();
            temp->next=newNode;
            temp=temp->next;
            p.pop();
            if(newNode->next)p.push(newNode->next); //如果节点后面还有子链表，丢回优先队列
        }
        return newHead->next; //不包括头节点，因为其为空
    }
```

##### 法二：分治法

我们可以通过分治的方式对所有列表进行两两的配对合并【如果当前链表数为奇数个，则最后一个链表轮空】
![[Pasted image 20241028212120.png]]
```c++

    return divide(lists, 0, lists.size());
}

ListNode* divide(vector<ListNode*>& lists, int l, int r){
    if(r == l)return nullptr;          // 区间不存在 返回空链表（任何链表与空链表合并为其本身）
    if(r - l == 1)return lists[l];  // 区间长度为1，直接返回链表lists[l]
    int mid = l + ((r - l) / 2);   // 取区间中点
    // 递归合并[l, mid)和[mid, r)两个区间的合并结果
    return mergeTwoLists(divide(lists, l, mid), divide(lists, mid, r));
}

ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
    if(list1 == nullptr)return list2;
    if(list2 == nullptr)return list1;
    ListNode* pre = new ListNode(); // 伪头节点，用于定位合并链表的头节点
    ListNode* node = pre;   // 新链表当前的最后一个节点，初始为伪头节点
    int val1;   // 用于获取链表1的节点值
    int val2;   // 用于获取链表2的节点值
    // 直到两个链表都遍历完了，合并结束
    while(list1 != nullptr || list2 != nullptr){
        val1 = list1 == nullptr ? INT_MAX : list1 -> val;   // 如果链表1已经遍历完，val1取最大值，保证链表2的节点被选择到 
        val2 = list2 == nullptr ? INT_MAX : list2 -> val;   // 如果链表2已经遍历完，val2取最大值，保证链表1的节点被选择到 
        if(val1 < val2){
            // 链表1的节点值更小，加入到合并链表，并更新链表1指向的节点
            node -> next = list1;
            list1 = list1 -> next;
        }else{
            // 链表2的节点值更小，加入到合并链表，并更新链表2指向的节点
            node -> next = list2;
            list2 = list2 -> next;
        }
        node = node -> next;    // 更新合并链表当前的最后一个节点指向
    }
    return pre -> next; // 伪头节点的下一个节点即为合并链表的头节点
}
```

按照前面说的技巧，根据刚才的分析来定义清楚每个递归函数应该做的事：

`PathSum` 函数：给定一个节点和一个目标值，返回以这个节点为根的树中，和为目标值的路径总数。
`count` 函数：给定一个节点和一个目标值，返回以这个节点为根的树中，能凑出几个以该节点为路径开头，和为目标值的路径总数。


```c++
class Solution {
public:
int pathSum(TreeNode *root, int sum) { 
	if (root == nullptr) return 0; 
	int pathImLeading = count(root, sum); // 自己为开头的路径数
	int leftPathSum = pathSum(root->left, sum); // 左边路径总数（相信它能算出来） 
	int rightPathSum = pathSum(root->right, sum); // 右边路径总数（相信它能算出来） 
	return leftPathSum + rightPathSum + pathImLeading; 
	} 

int count(TreeNode *node, int sum) { 
	if (node == nullptr) return 0; 
	int isMe = (node->val == sum) ? 1 : 0; // 能不能作为一条单独的路径呢？  
	int leftNode = count(node->left, sum - node->val); // 左边的，你那边能凑几个 sum - node.val ？
	int rightNode = count(node->right, sum - node->val); // 右边的，你那边能凑几个 sum - node.val ？ 
	return isMe + leftNode + rightNode; // 我这能凑这么多个 
	}
};
```

#### [236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)
真是无语了，今天的题看似很难其实代码很短，就是挺难想的......

考虑通过递归对二叉树进行先序遍历，当遇到节点 p 或 q 时返回。从底至顶回溯，当节点 p,q 在节点 root 的异侧时，节点 root 即为最近公共祖先，则**向上返回 root** 

终止条件：
当越过叶节点，则直接返回 null ；
当 root 等于 p,q ，则直接返回 root ；
（如果一个目标节点是另一个目标节点的祖先，那下面那个就会被挡住无法遍历到，使得最后左右子树返回值一有一无（见下面情况2））

递推工作：
开启递归左子节点，返回值记为 left ；
开启递归右子节点，返回值记为 right 

返回值怎么看？三种情况：
- **最顶端**root的左右子树都返回nullptr：就没有公共祖先，返回nullptr
- **最顶端**root的左右子树一个返回节点，一个返回nullptr：公共祖先就是返回的节点
- **最顶端**root的左右子树都返回节点：公共祖先就是**最顶端**root
```c++
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if(root == nullptr || root == p || root == q) return root;
        TreeNode *left = lowestCommonAncestor(root->left, p, q);
        TreeNode *right = lowestCommonAncestor(root->right, p, q);
        if(left == nullptr && right == nullptr) return nullptr; 
        if(left == nullptr) return right; 
        if(right == nullptr) return left; 
        return root; // if(left != null and right != null)
    }
};
```

#### [124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)

还是递归（欲哭无泪。。。）
难点：因为会出现下面这种情况：
![[Pasted image 20241124224956.jpg]]
输入：root = \[-10,9,20,null,null,15,7\]
输出：42
解释：最优路径是 15 -> 20 -> 7 ，路径和为 15 + 20 + 7 = 42

这种横过来的路径会比较难处理一点，因为他塞不进递归的常规步骤里。

二叉树 abc，a 是根结点（递归中的 root），bc 是左右子结点（代表其递归后的最优解）。
最大的路径，可能的路径情况：
```
    a
   / \
  b   c
```
- b + a + c
- b + a + (a 的父结点)
- c + a + (a 的父结点)
其中情况1，表示如果不联络父结点的情况，或本身是根结点的情况。这种情况是没法递归的，但是结果有可能是全局最大路径和。
情况 2 和 3，递归时计算 `a+b` 和 `a+c`，选择一个更优的方案返回，也就是上面说的递归后的最优解啦。
**另外结点有可能是负值，最大和肯定就要想办法舍弃负值`max(0,x)`。**

```c++
class Solution {
public:
    int fun(TreeNode* root, int& sum){
        if(!root)return 0;
        int left=fun(root->left,sum);
        int right=fun(root->right,sum);
        int case1=root->val+max(0,left)+max(0,right);  //注意舍弃负数
        int case2_3=root->val+max(0,max(left,right));
        sum=max(sum,max(case1,case2_3));
        return case2_3;  //这里只有情况2，3需要递归，所以返回的是case2_3而不是sum！！
    }
    int maxPathSum(TreeNode* root) {
        int sum=-9999999;  //有负数，不能取个0/-1就完事了
        fun(root,sum);
        return sum;
    }
};
```


## 2024.12.8
### 并查集（Union-Find）

#### 功能：解决图的连通性问题

#### 内容：
##### 成员变量
```
int count;  //整个图的连通分量的数量
vector<int> parent;  //节点i的父节点parent[i]
vector<int> size;  //节点i(若是根节点)的连通分量中的节点数目
```
##### 成员函数
```
void union(int p, int q); //连通两节点
int find(int x);  //找到节点x的根节点
bool connected(int p, int q);  //判断两节点是否连通
int count();  //计算图的连通分量数目
```

#### 函数实现
##### 初始化

**如何表示节点与节点之间的连通性关系呢？**
- 如果`p`和`q`连通，则它们有相同的根节点，用数组`parent[]`来表示这种关系
- 如果自己就是根节点，那么`parent[i] = i`，即自己指向自己
- 如果自己不是根节点，则`parent[i] = root id`
```c++
// 构造函数
public UF (int n) {
    count = n;  //最初，每个节点均是独立的，有n个连通分量
    parent.resize(n);
    size.resize(n);
    for (int i = 0; i < n; i++) {
        parent[i] = i;  //最初，每个节点均是独立的，即指向自己
        size[i] = 1;  // 最初，每个连通分量均为1
    }
}
```

##### Find函数
其实特别的简单：
```c++
private int find(int x) {
    while (x != parent[x]) {
        x = parent[x];
    }
    return x;
}
```
如何，是不是很简单，哈哈哈哈哈哈

##### Union函数

**介绍了存储的数据结构，那如何把两个节点连接起来呢？**
很简单，只需将其中任一一个节点的==根节点==指向另一个节点的==根节点==即可
![[22372116602286418vzmg723.svg]]

思路：
```
void union(int p, int q) {
    // 找到 p 的根节点 rootP
    // 找到 q 的根节点 rootQ
    // 如果已经在同一个连通分中，跳过
    // parent[rootP] = rootQ
    // 或 parent[rootQ] = rootP
    // 连通分量 --
}
```
代码：
```c++
public void union(int p, int q) {
    int rootP = find(p);
    int rootQ = find(q);
    if (rootP == rootQ) return;
    parent[rootP] = rootQ;
    //或 parent[rootP] = rootQ; 后文会讨论选哪个的问题
    count--;
}
```

##### connected函数

前面的内容实现过后，这里也会变得很简单：
```c++
public boolean connected(int p, int q) {
    int rootP = find(p);
    int rootQ = find(q);
    return rootP == rootQ;
}
```

#### 算法优化
##### 优化角度 1：平衡性优化

思路：当我们每次连接两个节点的时候，不希望出现头重脚轻的情况，而希望到达一种平衡的状态

使用额外的一个数组`size[]`记录**每个连通分量中的节点数**，每次均把节点数少的分量接到节点数多的分量上![[2250031660229403W4grn725 1.svg]]

```c++
public void union(int p, int q) {
    int rootP = find(p);
    int rootQ = find(q);
    if (rootP == rootQ) return;
    /******** 修改部分 ********/
    if (size[rootP] < size[rootQ]) {
        parent[rootP] = rootQ;
        size[rootQ] += size[rootP]
    } else {
        parent[rootQ] = rootP;
        size[rootP] += size[rootQ]
    }
    /********** end **********/
    count--;
}
```

##### 优化角度 2：路径压缩

思路：在==find函数==中，通过调整各节点的parent，使树高始终保持为**常数**
法一：迭代实现
```c++
int find(int x) {
    while (parent[x] != x) {
        // 进行路径压缩
        parent[x] = parent[parent[x]];
        x = parent[x];
    }
    return x;
}
```
法二：递归实现（优）
```c++
int find(int x) {
    if (parent[x] != x) {
        parent[x] = find(parent[x]);
    }
    return parent[x];
}
```

**注意：**「路径压缩优化」比「平衡性优化」更为常用。当使用了「路径压缩优化」后，「平衡性优化」可以不使用

##### [130. 被围绕的区域](https://leetcode.cn/problems/surrounded-regions/)（此题前文出现过，不过用的是DFS）
该题的难点在于在边界的’O‘判定为不封闭。
一个精妙的思路是：整一个虚拟节点`dummy`, 让所有在边界的’O‘都连接这个节点。最后在遍历判断的时候，只需在if上加一个限制条件，即可去掉连接到边界的情况。
![[1955451651060545MJSeqJ1.svg]]
```c++
class Solution {
public:
    class UF{
        public:
            int count;
            vector<int> parent;
            vector<int> size;
            UF(int n):count(n){
                parent.resize(n);
                size.resize(n);
                for(int i=0;i<n;i++){
                    parent[i]=i;
                    size[i]=1;
                }
            }
            int find(int x){
                while(x!=parent[x]){
                    x=parent[x];
                }
                return x;
            }
            bool connected(int p,int q){
                int rootP=find(p);
                int rootQ=find(q);
                return rootP==rootQ;
            }
            void Union(int p,int q){
                int rootP=find(p);
                int rootQ=find(q);
                if (rootP == rootQ)return;
                if (size[rootP] < size[rootQ]){
                    parent[rootP] = rootQ;
                    size[rootQ] += size[rootP];
                }
                else{
                    parent[rootQ] = rootP;
                    size[rootP] += size[rootQ];
                }
                count--;
            }
        };
  
    void solve(vector<vector<char>>& grid){
        int m=grid.size(), n=grid[0].size();
        cout<<m<<n;
        UF uf(m*n+1);
        int dummy=m*n;
        //连接边界
        for(int i=0;i<m;i++){
            if(grid[i][0]=='O')uf.Union(dummy,i*n);
            if(grid[i][n-1]=='O')uf.Union(dummy,i*n+n-1);
        }
        for(int j=0;j<n;j++){
            if(grid[0][j]=='O')uf.Union(dummy,j);
            if(grid[m-1][j]=='O')uf.Union(dummy,n*(m-1)+j);
        }
        //连接相邻点
        for(int i=1;i<m-1;i++){
            for(int j=1;j<n-1;j++){
                if(grid[i][j]=='O'){
                    if(grid[i-1][j]=='O'){
                    uf.Union(i*n+j,(i-1)*n+j);
                    }
                    if(grid[i+1][j]=='O'){
                    uf.Union(i*n+j,(i+1)*n+j);
                    }
                    if(grid[i][j-1]=='O'){
                    uf.Union(i*n+j,i*n+(j-1));
                    }
                    if(grid[i][j+1]=='O'){
                    uf.Union(i*n+j,i*n+(j+1));
                    }
                }
            }
        }
        //'O'->'X'
        for(int i=0;i<m;i++){
            for(int j=0;j<n;j++){
                if(grid[i][j]=='O' && !uf.connected(dummy,i*n+j))grid[i][j]='X';
            }
        }
    }
};
```

##### [128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)
并查集 + map
```c++
class UF {
private:
    vector<int> parent;
    vector<int> size;
public:
    UF(int n) {
        parent.resize(n);
        size.resize(n);
        for (int i = 0; i < n; ++i) {
            parent[i] = i;
            size[i] = 1;
        }
    }
    int find(int x) {
        // 路径压缩
        if (parent[x]!= x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    void unionSet(int p, int q) {
        int rootP = find(p);
        int rootQ = find(q);
        if (rootP == rootQ) return;
        parent[rootP] = rootQ;
        size[rootQ] += size[rootP];
    }
    int getMaxConnectSize() {
        int maxSize = 0;
        for (int i = 0; i < parent.size(); ++i) {
            if (i == parent[i]) {
                maxSize = max(maxSize, size[i]);
            }
        }
        return maxSize;
    }
};

class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
    // 使用unordered_map来记录元素值到其对应索引的映射，方便查找
        unordered_map<int, int> numMap;
        UF uf(nums.size());
        for (size_t i = 0; i < nums.size(); ++i) {
            if (numMap.find(nums[i])!= numMap.end()) continue; // 存在重复元素，跳过
            if (numMap.find(nums[i] - 1)!= numMap.end()) {
                uf.unionSet(i, numMap[nums[i] - 1]);
            }
            if (numMap.find(nums[i] + 1)!= numMap.end()) {
                uf.unionSet(i, numMap[nums[i] + 1]);
            }
            numMap[nums[i]] = i;
        }
        return uf.getMaxConnectSize();
    }
};
```


#### [210. 课程表 II](https://leetcode.cn/problems/course-schedule-ii/)
这个是拓扑排序的练习。拓扑排序是**DFS的逆序**。
```c++
class Solution {
public:
    vector<int> visited;
    vector<vector<int>> adjList;
    vector<int> res;
    bool valid=true;
    void DFS(int node){
        visited[node]=1;
        for(int n:adjList[node]){
            if(!visited[n]){
                DFS(n);
                if(!valid)return;
            }
            else if(visited[n]==1){
                valid=false;    //有环
                return;
            }
        }
        visited[node]=2;  //visited有三种状态
        res.push_back(node);
    }
    vector<int> findOrder(int numCourses, vector<vector<int>>& prerequisites) {
        adjList.resize(numCourses);
        visited.resize(numCourses);
        for(auto info:prerequisites){
            adjList[info[1]].push_back(info[0]);
        }
        for(int i=0;i<numCourses && valid;i++){
            if(!visited[i])DFS(i);
            if(!valid) return {};
        }
        reverse(res.begin(),res.end());
        return res;
    }
};
```
